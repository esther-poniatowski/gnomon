# Record schemas

The schemas of this folder declare the shape of each record type, so that a program validates a record and Ekphrasis renders it as a form, as the [decision on record schemas](../../../../docs/adr/record-schemas.md) states. The subfolder of views declares the shape of each view that gnomon generates, so that Ekphrasis displays it as a read-only form. Kleisis exports every schema of this folder and of its subfolder, through the [schema resources](../../../../specs/schema-resources.yml).

> [!IMPORTANT] Generated contracts
> Each contract is generated by `gnomon schemas` from its base schema and the vocabulary registry, and each template of the [record templates](../templates/_index.md) is rendered from the same sources. A field is changed in its base schema, and a value in the registry.

> [!IMPORTANT] One entry per schema
> Each entry gives the logical identifier `gnomon:<type>@<version>` of its schema, and is added in the edit that writes the schema.
