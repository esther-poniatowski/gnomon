# Repository specifications

Declares the schemas that `gnomon` exports to other repositories, in the formats that Kleisis reads.

- [Schema resources](schema-resources.yml): lists the contracts that `gnomon` exports and their sources
- [Schema registry](schema-registry.yml): maps each exported contract and each absolute `$id` to its file, as generated by Kleisis
