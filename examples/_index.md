# Worked inquiries

Shows completed inquiry records, which a researcher consults before filling the [record templates](../src/gnomon/data/templates/_index.md).

> [!IMPORTANT] Read by the test suite
> The tests parametrize over the folders of this directory. Their location and the expected folders are fixed in the [paths of the test suite](../tests/test_gnomon/paths.py), so a new or renamed folder is registered there as well.

## Inquiries

- [Phase exploration in active matter](active-matter-phase-exploration/_index.md): tests whether an open phenomenon can be specified without presupposing its macroscopic categories
- [Delayed generalization](grokking-delayed-generalization/_index.md): tests whether a known temporal regularity can be kept apart from its competing explanations
- [Anomalous scaling in turbulence](turbulence-anomalous-scaling/_index.md): tests whether a question about a limit system can keep its statistical target apart from requirements of universality
- [Tipping cascades in the Earth system](earth-system-tipping-cascades/_index.md): tests whether a prediction can carry several sources of uncertainty about a partially known system
- [Stable microbial coexistence](microbial-stable-coexistence/_index.md): tests whether necessary and sufficient conditions stay distinct across model variants
- [Localized Swift-Hohenberg states](swift-hohenberg-localized-states/_index.md): tests whether a description can name the features it seeks without supplying their values
- [Neural tangent dynamics](neural-tangent-kernel-model-knowledge/_index.md): tests whether an inquiry can specify the knowledge it seeks about a formal class of models

## Framework trials

- [Framework issue synthesis](../test/framework-issues-synthesis.md): separates the framework changes that the cases support from local edits
- [Handoff — framework corrections](../test/framework-corrections-handoff.md): assigns each correction that the cases call for an owner and an approval control
- [Issues exposed by the answer and assessment trials](../test/answer-assessment-template-issues.md): separates defects of the shared templates from failures of individual candidates
