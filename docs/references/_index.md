# References

Gathers the inventory of external frameworks and literature, each stated on its own terms, on which the decisions and the goals of `gnomon` draw.

## Principles of reasoning

- [Reasoning principles by field](reasoning-argumentation-principles-by-field.md): compares the demands that each discipline places on a valid argument, an explanation and an understanding
- [Reasoning principles across fields](reasoning-argumentation-principles-cross-field.md): organizes the demands on reasoning into one taxonomy across disciplines

## Formal domains of reasoning

- [Formal reasoning domains overview](formal-frameworks-overview.md): compares the formal domains that model an epistemic state and the steps that change it
- [Proof theory](proof-theory.md): models an epistemic step as a rule that transforms a sequent
- [Dependent type theory](dependent-type-theory.md): models an epistemic step as a tactic that refines a goal type within a typing context
- [Classical AI planning](ai-planning-pddl.md): models an epistemic step as an operator that changes a world state under the closed-world assumption
- [Hierarchical task network planning](hierarchical-task-network-planning.md): models the decomposition of a compound task into subtasks by methods
- [Argumentation theory](argumentation-theory.md): computes the acceptable arguments from a set of arguments and an attack relation
- [Belief revision and dynamic epistemic logic](belief-revision-dynamic-epistemic-logic.md): models the change of an epistemic state under new information
