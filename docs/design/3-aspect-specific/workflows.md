## Criteria

### Target question with explicit output and boundary ^t3-target-question-with-output

An inquiry begins from a target question with an explicit intended output and an explicit boundary declaration (what is in scope, what is out of scope, what evidence is admissible, what would count as an answer).

### Minimal answer subgraph ^t3-minimal-answer-subgraph

The inquiry's answer is built from a minimal answer-subgraph: only the canonical objects and assembly moves epistemically necessary for the target. Objects without a justified place in the subgraph are flagged.

### Justification for each new object ^t3-justify-each-new-object

Each new object introduced into an inquiry justifies four points:

- why it exists;
- which question it serves;
- what gap it fills;
- what would break if absent.

The first three are recorded as strategic annotation in the introducing assembly per [strategic annotations attach to the assembly](vendor/gnomon/docs/design/2-architecture/reasoning-structure#^t2-reasoning-annotation-attachment); the fourth is auditable via the dependency graph.
