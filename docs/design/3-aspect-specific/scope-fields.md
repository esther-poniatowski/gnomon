## Criteria

### Scope field set for inquiry boundary ^t3-scope-field-set

An inquiry's scope is recorded by an explicit field set: target question, included subquestions, excluded subquestions, admissible evidence kinds, admissible methods, required answer form, stopping criteria. A scope declaration that omits any of these is incomplete.
