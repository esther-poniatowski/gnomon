# Argument and reasoning proposals

Two questions divide these proposals: how a justification path is assembled from canonical objects, and how the steps inside a single derivation are encoded. Three variants answer the encoding question independently, and each is kept as a separate record.

| Proposal | Content |
| --- | --- |
| [Argument bundles](argument-bundles.md) | Explicit subgraphs of canonical objects, constructed to answer one target question. |
| [Primitive operations](primitive-operations.md) | The conditions under which a schema counts as primitive, so that the regress of informal placeholders terminates. |
| [Derivation encoding — variant C](derivation-proof-encoding-C.md) | The three failures that make a sequence of claims opaque to a later reader. |
| [Atomic epistemic acts — variant E](derivation-proof-encoding-E.md) | Epistemic acts that perform a single transformation, proposed as the atoms of a derivation. |
| [Derivation encoding — variant G](derivation-proof-encoding-G.md) | The scale below the decomposition of a question, where the steps of one derivation are recorded. |
