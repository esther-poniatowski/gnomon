# Taxonomy - P2

For initial stability, the minimal canonical set should be:

|Core type|Justification|
|---|---|
|`question`|teleological anchor|
|`definition`|semantic anchor|
|`claim`|generic proposition layer|
|`proof`|justificatory layer|
|`assumption`|local logical control|
|`example`|illustration and testing|
|`mechanism`|explanatory object distinct from formal claim|
|`comparison`|explicit relational judgment|
|`scope`|boundary control|
|`decision`|meta-rational trace of methodological choices|

Then define specialized variants gradually:

- `lemma`, `theorem`, `corollary` as claim variants
- `counterexample` as example variant
- `taxonomy` as comparison-adjacent domain object
- `open_question` as question variant

This is preferable to introducing all specialized types immediately.
