
# Families of objects

## Proposal F (functional)

**Alternative factoring along three functional axes** (8 primitives):

|Stratum|Function| Primitives            |
|---|---|---|
|Semantic|What entities exist and mean| CONCEPT, MODEL        |
|Propositional|What is claimed to be true| CLAIM, QUESTION       |
|Inferential|How reasoning moves occur| ARGUMENT, EXPLANATION |
|Procedural|How inquiry is conducted| METHOD                |
|Framework|What conditions apply| FRAMEWORK             |

**Structural advantages**:

1. The functional strata make the ontological architecture explicit and navigable — a reasoning graph annotator immediately understands which stratum a node inhabits.
2. EXPLANATION appears at the same level as ARGUMENT, clarifying that they are co-equal inferential operations rather than EXPLANATION being a derivative structure.
3. The semantic / propositional separation (CONCEPT ≠ CLAIM) and the representational / inferential separation (MODEL ≠ ARGUMENT) are preserved.

**Structural disadvantages**:

- QUESTION's placement in the propositional stratum is debatable — questions are not truth-apt propositions; they are better understood as epistemic directives.
- METHOD and FRAMEWORK are potentially conflatable at the procedural/framework level, though their functional distinction is clear.

**Verdict**: This factoring is structurally superior to the proposed ontology precisely because it makes the ontological architecture a first-class epistemic object. It should be adopted as the organizational principle of the recommended ontology.

| Criterion                  | Proposed (7) | Functionally Stratified (8) |
| -------------------------- | ------------ | --------------------------- |
| **Understandability**      | Good         | Excellent                   |
| **Intelligibility**        | Good         | Excellent                   |
| **Expressive adequacy**    | Moderate     | High                        |
| **Boundary purity**        | Moderate     | Good                        |
| **Structural clarity**     | Moderate     | Excellent                   |
| **Reasoning transparency** | Moderate     | Excellent                   |
| **Operational usefulness** | Good         | Good                        |
| **Token/type resolution**  | Absent       | Requires explicit addition  |
| **Relational vocabulary**  | Absent       | Requires explicit addition  |

The functionally stratified 8-primitive ontology dominates the proposed ontology on every criterion except operational usefulness (where they are comparable), precisely because it makes architectural structure transparent.

## Proposal P

A minimal but sufficiently expressive ontology can be organized into six canonical families.

| Family                                  | Role                                                                                                                                                                             | Examples                           |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| **Question-like objects**               | Define the **targets of inquiry themselves** (not inquiry bundles)                                                                                                               | question, problem, subquestion     |
| **Conceptual objects**                  | Fix the **semantic vocabulary** of the framework                                                                                                                                 | concept, definition, notation      |
| **Statement-like objects**              | Carry truth-apt content.                                                                                                                                                         | assumption, claim, conjecture      |
| **Justificatory objects**               | Connect statements to their grounds.                                                                                                                                             | proof, derivation, argument-sketch |
| **Constructive and evidential objects** | Support actual research reasoning rather than only theorem exposition                                                                                                            | example, counter-example, evidence |
| **Source-grounding objects**            | If provenance and traceability is operationally important, this family should be introduced. If provenance is secondary, these can remain metadata instead of canonical objects. | source, reference, evidence        |
