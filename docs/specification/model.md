# Model record

> [!QUESTION] Goal: what does a researcher write in each field of a model record, and when is each field required?

The [theory of models and bindings](../epistemology/objects/answer/model-and-binding.md) states the grounds of these fields.

A model is a record of its own, which several answers can ground, such as the [answers of two aims](answer.md#^answer-elements) that the model serves. Each answer cites the model instead of declaring it again. ^model-record

A model is a system studied as a stand-in for a target: laws relate quantities that units bear and that take values over indices. Therefore, the model is declared with the blocks and the fields of a [target system](../epistemology/objects/subject/target-system.md), and its laws and organization with those of a [background record](../epistemology/objects/knowledge/background.md). The value sets of the two formats already carry every distinction that a model draws, so no separate vocabulary is needed. The model $M$ holds the elements below. None of them refers to one question, since several questions can share the model. ^model-elements

| Element | When it is required | Content | Constraint on the element | Examples |
| ------- | ------------------- | ------- | ------------------------- | -------- |
| Background — the record from which the laws of the model are derived | when a law of the model carries the warrant `derived` | the identifier of one [background record](../epistemology/objects/knowledge/background.md) | — | the admitted training laws of the networks of a class |
| Derives from | for a derived model | the identifiers of its parents: the target system, or other models | a root model, which no operation derives, names no parent | the target system of the grokking networks |
| Operations | for a derived model | one entry per operation, in the order applied, typed as the [derived models](../epistemology/objects/answer/model-and-binding.md#^derived-models) define the kinds | each symbol of the model is declared in a parent, defined over visible symbols, or yielded by an operation | the expansion of an active field near onset |
| Operations: id | in each entry | a descriptive identifier, unique within the record | — | `weak-amplitude` |
| Operations: kind | in each entry | restrict · limit · change-coordinates · aggregate · approximate · idealize · extend | typed relative to the parent, never to the target | `approximate` |
| Operations: acts on | in each entry | the symbols of a parent on which the operation acts, written `RECORD.SYMBOL` | — | the field of a parent |
| Operations: yields | in each entry | the symbols of this model that realize the operation | — | the amplitude of the pattern |
| Operations: retires | when the model no longer carries a symbol of a parent | the symbols of a parent that this model drops | an expression of the model uses no retired symbol | the field, replaced by its amplitude |
| Operations: regime | for an approximation, and for any operation that holds in a regime only | the regime, as an expression over declared symbols | — | an amplitude small against one |
| Operations: error class | in each entry | exact · controlled · uncontrolled · singular | — | `controlled` |
| Operations: bound | when the error is controlled | the bound on the error, as an expression over declared symbols | — | an error of the order of the squared amplitude |
| Operations: order | for a singular limit, or for limits that do not commute | the order in which the limits are taken | — | the width to infinity before the time to infinity |
| Operations: gain | in each entry | the derivation or the factor that the operation makes available | — | the amplitude equation of the pattern near onset |
| Operations: rests on | in each entry | the result, the limit or the source that justifies the operation | — | the expansion near the onset of instability |
| Constituents $C$ | for a root model; for a derived model, the bearers that its operations yield, such as the coarse bearers of an aggregation | the units that the model treats as bearers | - either units defined by a stated map from the [constituents declared for the target](../epistemology/objects/subject/target-system.md) (e.g. coarse-graining, mode decomposition, aggregation, quotient by a symmetry), or units of the model alone, related to the target only through a binding; <br>- the organization $O$ and the terms $V$ range over these units | the slow eigenmodes of the connectivity (defined by a map); the four tipping elements of a box model of the Earth system (units of the model alone) |
| Index sets | when a quantity of the model is indexed by a set that the target does not declare | the set, its extent and its structure, in the format of a target system | — | a coarse-grained scale; a mode number |
| Index sets: dimensional formula | when a law of the model takes a derivative along the index | the formula of the coordinate that the set collects, as for an [index set of the target](target-system.md) | a derivative along the index divides by this formula | the spatial domain, `L`; the time axis, `T` |
| Variables | for a root model, for each quantity that varies in the model; for a derived model, each quantity that its operations yield, such as a collective variable or a reduced coordinate | per variable, its own symbol, signature and value set, and its construction: an expression over the symbols of the model, or a map other than the identity from the quantities that the target declares | - a map from the declarations of the target defines a [derived term](../epistemology/objects/answer/model-and-binding.md#^derived-terms); <br>- a variable never enters by reference to a target quantity, nor by an identity map, which is a reference under another name | the population rate; the overlap with a stored pattern |
| Variables: dimensional formula | when a law of the model is checked for dimensional homogeneity | the formula of the quantity, as for a [variable of the target](target-system.md); a parameter states it in the same way | a law naming a quantity without one stays unchecked, and a problem that declares a formula reports it | the population rate, `T^-1`; an overlap, `1` |
| Parameters | when the model holds a quantity fixed | the same content as for a variable, for each quantity that the model holds fixed while the phenomenon unfolds | the parameters that a binding calibrates are marked in that binding, not here | the coupling strength; the adaptation timescale |
| Laws or structural relations $L$ | for a root model; for a derived model, the laws that its operations yield | the dependences that link the terms $V$ | - each law states its *warrant* (`derived`, `posited`, `fitted` or `measured`) together with its grounds, and, as a [law of the background](../epistemology/objects/knowledge/background.md#^law-warrant) does, its origin and the range over which it is established; <br>- a law marked `derived` names its descent, through a [derivation record](derivation.md) that states it as a consequence or through an origin that holds the derivation; <br>- a law derived through an operation of the model, such as a limit or an approximation, names that operation, which states the error class of the derivation | the mean-field rate equations (derived through a mean-field limit); the stability condition that follows from them (derived); a transfer function obtained from recordings (fitted) |
| Organization $O$ | when the parts or the laws stand in a relation on which the behavior of the model depends | per relation, the tuples that it connects and the laws that state it, in the format of a background record | its constituents follow the [definition of a mechanism](../epistemology/objects/answer/mechanism.md) | a delayed feedback loop, in which excitation drives inhibition and is suppressed in return |
| Assumptions of the laws | when a law of the model holds only under an assumption, such as a limit | per assumption, its motive, the gain that it provides, and whether it is removable, as the [rule on idealizations](../epistemology/objects/answer/answer-form.md#^idealizations) defines them | - only the assumptions that the laws of the model require; <br>- whether an assumption is an idealization, and over which range it holds, depends on the target, so each answer that rests on the model classifies it | the mean-field limit, which closes the rate equations (motive: limit; controlled) |

- **A model derived from another model names its parents.** A reduced model, a limit model or a model corrected by de-idealization is derived from parent models by the operations that the [derived models](../epistemology/objects/answer/model-and-binding.md#^derived-models) type. ^model-parents
