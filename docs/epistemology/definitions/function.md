# Function

> [!QUESTION] Goal: which sense of "function" does a statement about a component use?

The **function** of a component is the contribution of its activity to an object beyond the component: a capacity of the containing system, or the history that retained the component. The term is distinct from a mathematical function, a map between sets. The other notes of this folder also use the mathematical sense.

## Senses

| Sense | A component has the function $F$ when | Example | Source |
| --- | --- | --- | --- |
| Causal role | its activity $F$ contributes to a capacity of the containing system, in an analysis of that capacity into the capacities of the parts | the heart pumps blood, and pumping contributes to the circulation | [cummins1975] |
| Etiological | it is present because doing $F$ had consequences that led to its presence, as in natural selection | the heart is there because pumping blood was selected | [wright1973] |

## Distinctions

- **The two senses are told apart by the source of the function.** A causal-role function is fixed by a capacity chosen by the inquirer, so it is relative to an analysis. An etiological function is fixed by a past history, so a component can retain a function no longer performed.
- **A function and an activity differ by relativity.** The criterion is stated in the [vocabulary of activity](activity.md).

## Consequences for a record

- **A functional answer is one value of the requested relation.** The [requested relation](../requested-relation.md) lists function among the relations that an answer may be asked to establish. The choice between the two senses fixes the evidence required of the answer: an analysis of a capacity, or a selective history.
- **A causal-role function requires the capacity to be named.** When a record ascribes a causal-role function, it must state the capacity of the system to which the component contributes. The requirement follows from the relativity of functions to capacities.
