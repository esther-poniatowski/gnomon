# Answer and assessment

Defines a candidate answer and the tests that decide whether it succeeds, the fourth layer of the specification of a question.

- [Answer form](answer-form.md): defines a candidate answer in the terms that the question has already fixed
- [Model and binding](model-and-binding.md): defines the model on which an answer rests and its binding to the phenomenon
- [Mechanistic answer](mechanism.md): defines the answer to a question that requests a mechanistic relation
- [Conditions of satisfaction](satisfaction-conditions.md): fixes, before any answer is evaluated, the tests that decide whether it succeeds
