# Specifying the target system

> [!QUESTION] Goal: what must be fixed to specify the system that an inquiry is about?

The target system is the first component of the [subject of inquiry](subject-of-inquiry.md).

> [!IMPORTANT]
> A target system is delimited within the world by the modeller, through partitioning and abstraction. The target system therefore already results from a modelling step [elliottgraves2020].

- **The specifications are admitted as given.** The record keeps the laws and properties that are admitted *a priori* as relevant to characterizing the system. The inquiry may nevertheless seek new laws. Formal and empirical targets differ only in the closure of the admitted laws, and that closure decides what a new law may be: For a formal target, the laws define the system, so a new law must be derivable from them, for instance an effective equation obtained in a mean-field limit. For an empirical target, a new law may be independent of the admitted ones, for instance a newly discovered plasticity mechanism. *Example*: the Edwards–Anderson spin glass consists of $N$ Ising spins $s_i\in\{-1,+1\}$ on the sites of a lattice. The spins interact through random couplings $J_{ij}$ between neighbouring sites, with energy $H=-\sum_{\langle ij\rangle}J_{ij}s_is_j$. The state space is $\{-1,+1\}^N$, and the site positions and the couplings are parameters, fixed while the spins evolve [edwards1975]. ^constituents

- **The option "No external target" of the target type covers questions about a model class itself**: its [consequences, regimes, limits and structural properties](epistemic-aim.md).

- **The reference class is generated by the other specifications.** Its members satisfy the constituents, the variables and the laws, and their parameters lie in the admitted value sets as restricted by $D$. When the target is a particular system, the class has a single member. In the phenomenon, the members of the reference class are the instances indexed by $k$.

> [!IMPORTANT] No redundancy
> The reference class records only a name and, when needed, selection criteria, and restates none of the other specifications. No restatement is needed, because the other specifications together already form a schema. Each member of the class instantiates that schema with its own parameter values, as a theory specifies a family of models [winther2020].

- **Selection criteria are needed only when membership depends on an outcome of the dynamics**, for a formal class as for an empirical one. A restriction on prior properties, such as the species and brain area of recorded animals, belongs to the domain of the question that imposes it, as eligibility criteria define the population of a clinical trial [ich2019].

- **A criterion on an outcome of the dynamics can create associations that the full class does not show.** *Example*: across the full class, the learning rate and the initialization scale are set independently, but training converges only when their product stays under a threshold. Among the converged networks, a large learning rate then co-occurs with a small initialization scale. This association comes from the selection alone, since convergence is a common effect of both factors [hernan2004]. Each selection criterion is therefore marked as fixed *a priori* or as dependent on an outcome. A claim about members chosen by an outcome transfers to the full class only once it has been checked for this selection bias.

- **State variables fix how the phenomena can be expressed.** The reason is that the explanandum variable of a phenomenon is a *function of the system's state variables* (an "observable"). Likewise, a variable defined over one constituent, or over a pair of them, corresponds to the [components and relations of a mechanism](mechanism.md).

- **Each entry of a signature resolves to a constituent kind or to an index set, and the two cases are read differently.** An entry resolving to a constituent kind names the bearer of the quantity. In a system with several kinds of unit, such an entry therefore fixes which kind bears the quantity. An entry resolving to an index set, by contrast, names the set along which the quantity varies. A signature entry that resolves to neither is a *defect*.

- **A parameter or a variable names the signature that it takes**, with one entry per place, each a constituent kind or an index set. A quantity of a single unit names one constituent kind, and a quantity of a pair two. A quantity of the whole system names none. The places are generic: a connectivity weight defined over two neurons holds for any pair. A quantity whose single value holds for every tuple is marked as shared. A variable that is an aggregate is declared, in addition to its signature, with its defining map, "[variable] := [function of constituent variables]". ^places

- **Constituent states determine an aggregate, but not a quantity of the whole system.** An aggregate is therefore a *function on the state space*. *Examples*: the center of mass is a mean of positions weighted by mass, the temperature of a gas a mean kinetic energy, a population rate a mean over neurons. The volume of a container, by contrast, is a quantity of the whole system. ^aggregate-variables

- **An aggregate is a legitimate variable only if interventions on it have unambiguous effects.** For example, total cholesterol is ambiguous: raising it through LDL or through HDL has opposite effects on heart disease [spirtes2004]. A mean rate over excitatory and inhibitory neurons is ambiguous for the same reason. The requirement comes from consistency between levels: a model over aggregates must stay consistent with the model over constituents. Consistency holds only if each intervention on an aggregate corresponds to interventions on the constituents [rubenstein2017]. A declared aggregate therefore commits the record to this correspondence. [The individuation test holds each candidate answer to that correspondence](satisfaction-conditions.md). ^aggregate-admissibility

- **An aggregation map is carried by its variable, not by a law.** Such a map merely *introduces* its quantity, so it cannot be false of the system. *Example*: the map "population rate := mean of the constituent rates". The expression of a law, in contrast, asserts a claim that can be false. A bridge law falls on the side of the laws: it *identifies a separately measured quantity with an aggregate*, so it is a factual hypothesis. *Example*: the temperature read by a thermometer equals the mean kinetic energy of the molecules, up to a constant. In reduction theory, however, a bridge law has the status either of a stipulation or of an empirical hypothesis [nagel1961]. A bridge law that states an empirical hypothesis belongs to the laws, under the role measurement.

- **Internal variables form the state of the system $S$**: $S$ determines their values, as a causal model fixes its endogenous variables [pearl2009]. The law that determines an internal variable, however, need not be known: such a variable may be only measured, and its law may be admitted, sought by the inquiry, or left open.

- **An external system is fixed by its symbol, the variables that it shares, the constraints that it imposes on them, and its own quantities.** *Examples*: the temperature of a heat bath, the latent dimension of a generator of inputs, the weights of a decoder. Each such quantity is declared among the parameters or the exogenous variables of the record, and names its owner. One symbol table therefore serves the whole record, and [a question narrows a quantity of an external system as it does a parameter of $S$](domain.md). A law of an external system, by contrast, is omitted when it involves no shared variable, because such a law cannot act on the target. ^external-parameters

- **A variant that no declaration carries names a member that the record cannot generate.** The other members remain describable, but that variant has no schema at all. The class therefore states a disjunction of variants, and the declarations support only some of its terms. A record may admit the gap by marking the variant open in its [maturity](subject-of-inquiry.md), the field reserved for such gaps. Otherwise, the gap is reported. To detect the gap, the check counts the entries that carry the variant, across every block of declarations in the record. Occurrences of the variant's name do not count, because that name recurs in its own prose and in the mark that admits the gap. ^unborne-variant

- **A selection criterion conditions membership on an outcome, whereas a restriction on prior values belongs to the question.** A target system serves several phenomena and questions, so a restriction written there binds every inquiry built on the record. Such a binding restriction is correct when the class is a *selected* population, because members selected on an outcome of the dynamics form a class that supports different inferences, and every inquiry must account for that change [lundberg2021]. Such a restriction is incorrect, by contrast, when one inquiry merely asks its question of some members and another would ask it of the rest. That partition of the members is a [restriction of the domain, imposed by the question](domain.md). A restriction that bears on no single quantity is stated as a joint condition. ^selection-on-outcome

- **A variant alters the declarations of a member, whereas a domain restriction changes only the values of its quantities.** When members of one class share every declaration and vary only in their parameter values, a [restriction of the domain](domain.md) captures the difference. Members may instead differ in which quantities and which laws they carry at all. No restriction of values captures such a variation: a consumer model with explicit resource pools and one with direct interaction coefficients have distinct state spaces. The declarations nevertheless stay in one symbol table, because the resolver and every reference between records assume that layout. A variant partitions the symbol table, and its mark labels each entry carried by only some members. An entry left unmarked holds for the whole class, so it may not name a symbol that only some members have. Whether an entry names such a symbol is read from the fields through which its kind refers to symbols. A law refers to it through its expression, and an external system through the variables that it shares. A relation of the organization refers to a symbol through the parts that it runs between and through its realizing laws. The mark itself must name a declared variant, because an undeclared mark releases its entry from holding for the whole class without assigning it to any member. ^variants

- **Every law is admitted *a priori*, and its warrant names the grounds.** The grounds differ between laws. A law derived from other laws holds only as long as those laws hold. A law that is posited, fitted or measured rests on a choice, a fit or an instrument, so new evidence revises such a law first. The warrant is therefore a property of the *law*. The warrant also propagates along dependence: a result resting on a measured law inherits the exposure of that law to revision. An answer built on the result inherits that exposure in turn. A [candidate answer states the warrant of its own laws in the same vocabulary](answer-form.md), so a chain of dependence can be read from end to end. ^law-warrant

- **A relation between two parts is internal to $S$.** The external systems fix the boundary of $S$, so they hold no relation whose ends both lie inside $S$. Such a relation is therefore stated in the organization. The organization names the laws stating the relation and the ordered tuples along which it runs. Those laws supply the quantities that carry the relation, namely those indexed by every place, so the organization declares none of its own. The reach comes last in each tuple, so the order of the components gives the direction. A tuple of three or more components states a joint relation. No pair of ends can state such a relation: two populations may together change the growth of a third without either one affecting it alone. ^organization

- **A relation whose ends are laws names and orders those laws, without a carrying quantity.** In a mechanism, the activities are organized as well as the parts [craver2007]. Two laws may therefore stand in a relation: for example, one law may run only after another has completed, or hold only while another holds. Such a relation puts the reach last. No expression carries such a relation, because no quantity is indexed by a law. A relation between laws adds content only where the law expressions leave the order open. Where the laws share an index, that index already fixes the order. *Example*: a distribution stated at step zero beside an evolution written over the later steps. For this reason, no record of the corpus states a relation between laws. ^law-ends

- **A constraint of an external system is a claim, and is recorded with the fields of a law.** The constraint can be false of the system and its environment together. The constraint nevertheless stays with the external system imposing it, not among the laws, for two reasons. First, the block of external systems exists to state the boundary. Second, each law bears on the target alone. ^external-constraint-shape

- **An external system belongs to a class, as the target does.** The target is fixed by a reference class that its specifications generate. For an external system, a name in words and the constraints that it imposes at the boundary leave its kind open, and the class fixes that kind. An answer that appeals to the external system therefore invokes a *kind*. Two inquiries may then appeal to the same kind. The constraints, by contrast, restrict the variables that the external system shares, and therefore also carry any consequence of the class at the boundary. ^external-class

- **External systems enter the specification only through the variables that they share with $S$.** An open system interacts with its environment through variables shared at its boundary [willems2007]. The external systems are therefore specified by the properties that constrain those shared variables. These properties meet [the condition for admitting a specification: they change the admissible answers](subject-of-inquiry.md#^inclusion-test). For example, an answer may explain the phenomenon by the structure of the inputs, such as the latent variables that generate them [goldt2020]. An answer may also appeal to the class of external system that reads the outputs, such as a linear decoder. A restriction of the parameter ranges of an external system, however, belongs to $D$, as it does for $S$.

- **The boundary is the set of shared variables, declared without a direction.** In the behavioral approach, every interconnection is a set of shared variables, with no prior partition into inputs and outputs [willems2007]. Where a partition into inputs and outputs applies, the declarations still recover that split: a shared exogenous variable is set outside $S$, and a shared state variable is determined inside $S$. A shared state variable that an external system also constrains closes a loop. The boundary therefore needs no explicit direction: the declarations already fix the orientation.

- **The partition of variables is only provisional.** The constituents, the state variables and the shared ones record the partition that the researcher *stipulates*. *Examples*: an isolated slice, or a closed loop with a task environment. Some inquiries, however, partly *establish* the relevant partition themselves. *Example*: in [constitutive explanation](requested-relation.md), a part belongs to the mechanism only if its activity and the system's behavior can each be changed by intervening on the other ("mutual manipulability") [craver2007]. The inquiry may then move a variable across the boundary, for instance by enlarging $S$ to include the task environment.
