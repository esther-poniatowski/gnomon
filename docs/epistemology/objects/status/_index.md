# Statuses of epistemic objects

Places each epistemic object of an inquiry, and tells apart the statuses that those objects bear.

> [!IMPORTANT] Read after the answer
> The notes of this folder use every object defined before them, from the problem to the assessment of an answer, so they are read after the notes of the [answer and its assessment](../answer/_index.md).

- [Epistemic objects](epistemic-objects.md): decides what counts as an epistemic object, and finds the role, the product type and the record kind of each one
- [Statuses and acceptance](statuses-and-acceptance.md): tells apart the statuses that an item of the state can bear, and decides how an answer enters the accepted knowledge
