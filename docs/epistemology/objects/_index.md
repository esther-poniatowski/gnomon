# Objects of inquiry

Defines the epistemic objects that an inquiry states, and the statuses that those objects bear.

- [Problem](problem/_index.md): defines the problem that opens an inquiry, and the obstacles that keep its demand unmet
- [Question](question/_index.md): defines a question, the specification of its subject, task and virtues, and the conditions under which it can be answered
- [Subject of inquiry](subject/_index.md): defines the objects that a research question is about
- [Knowledge](knowledge/_index.md): defines the knowledge that an inquiry takes as given, and the dependence of its claims on one another
- [Epistemic task](task/_index.md): defines the kind of knowledge that an answer must deliver, and the qualities by which admissible answers are compared
- [Answer and assessment](answer/_index.md): defines a candidate answer and the tests that decide whether it succeeds
- [Statuses of epistemic objects](status/_index.md): places each epistemic object of an inquiry, and tells apart the statuses that those objects bear
- [Concept](concept/_index.md): defines the concepts that a project uses to describe its objects, apart from their names
