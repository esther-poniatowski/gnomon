# Quantities and states

Fixes the senses of the terms that name the quantities, the states and the given constraints of a described system, and the criteria that separate those terms.

> [!WARNING] Notes with neighboring names
> [Condition](condition.md) fixes the senses of the term, whereas the [domain of conditions](../../objects/subject/domain.md) states the restrictions that a question imposes on admitted values, and the places that hold them.

- [Variable, value, observable, parameter and data](variable-value-observable.md): identifies the formal object introduced by a declaration of a quantity
- [Scale and level](scale-and-level.md): decides which statements about values are meaningful, and which sense of scale or level a statement uses
- [State, state space and configuration](state-and-configuration.md): checks whether a set of values forms a complete state
- [Condition](condition.md): tells apart the senses of "condition", from a constraint on a system to a requirement on an answer, and assigns each condition its place
- [Invariant and symmetry](invariant-and-symmetry.md): states which transformations a claim of invariance refers to
