# Bearers and systems

Fixes the senses of the terms that name the bearer of a description and its role relative to a boundary, and the criteria that separate those terms.

## Bearers

- [Entity, object and thing](entity-object-thing.md): names the bearer of a description at the right degree of generality
- [System, constituent and environment](system-constituent-environment.md): assigns each object of a description its role relative to a boundary
- [Property, attribute, predicate and relation](property-attribute-predicate.md): tells a feature of a bearer from the concept and the expression that represent it
- [Kind, class and population](kind-class-population.md): fixes the collection over which a law, a model or a claim generalizes
