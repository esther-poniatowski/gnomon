# User guide

Guides the use of `gnomon`, from the filling of the records of an inquiry to the commands that check them.

- [Starting an inquiry from an empty folder](first-inquiry.md): begins the greenfield route and builds a first inquiry up to a candidate answer that the check accepts
- [Starting from existing research](adopting-existing-research.md): begins the adoption route from one active problem or question without converting the surrounding project
- [Following one inquiry](tutorial.md): walks through one worked inquiry stage by stage, with the itinerary step and the command of each stage
- [Filling the records of an inquiry](filling-records.md): leads a researcher from a research problem to a folder of records that the checks accept
- [Installation](installation.md): guides the installation of the package and states the Python version that it requires
- [Recovering the integrated workflow](recovery.md): restores an interrupted integrated workflow, including records whose contracts changed, without losing authored records
- [Capability status](capabilities.md): determines which research outcomes can be relied on in the current release
- [CLI reference](cli-reference.md): looks up the arguments and the options of each command of the `gnomon` entry point
- [Field index](field-index.md): looks up a field of a record by its path, with the row of the specification that documents it

> [!IMPORTANT] Entry routes
> A new inquiry starts with the greenfield tutorial. An active part of existing research starts with the adoption guide. The [capability status](capabilities.md) states the current boundary of each route.
