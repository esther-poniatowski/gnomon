# Active-matter phase exploration

[The active-matter problem and its expressive burden](description.md) require the framework to specify an exploratory search whose possible phenomena are not known in advance.

- [The formal class of nonreciprocal stochastic systems](target-system.yml) fixes the local two-species dynamics while admitting lattice and continuum realizations.
- [The open search for collective phases](phenomenon.yml) specifies the search space and its detection standard without assuming a phase catalogue.
- [The phase search across size and dimension](question.yml) requests separate finite-size and thermodynamic-persistence results without an explanatory relation.
- [The spatial-domain constructors](operators.yml) type the continuum and lattice extents used by the two target variants.
- [The current specification assessment](issues.md) separates the residual type-language limitation from the deliberately open phase product.
- [The symbols and operators this problem declares](vocabulary.yml) collects every declaration across its records, so a new notation can be chosen without reopening each file. The `gnomon vocabulary` command builds [a table of the same record](vocabulary.md) on request.
