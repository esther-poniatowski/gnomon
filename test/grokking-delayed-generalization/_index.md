# Delayed generalization

[Delayed generalization raises questions about its cause and duration](description.md), so the case tests whether the framework can separate the temporal regularity from alternative explanations.

- [The finite neural-network training system](target-system.yml) separates evolving parameter state from fixed training specifications and external task data.
- [The delayed-generalization regularity](phenomenon.yml) specifies the operational delay observable and its distribution across initializations.
- [The mathematical explanation sought](question.yml) fixes the epistemic requirements and substantive foils without selecting a mechanism.
- [The problem-specific set constructor](operators.yml) types the realized training and held-out samples as subsets of the task's example space.
- [The field-level representational findings](issues.md) identify the capabilities that the instantiated records cannot express directly.
- [The symbols and operators this problem declares](vocabulary.yml) collects every declaration across its records, so a new notation can be chosen without reopening each file. The `gnomon vocabulary` command builds [a table of the same record](vocabulary.md) on request.
