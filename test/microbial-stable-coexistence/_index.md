# Stable microbial coexistence

Stable coexistence tests whether the framework can keep every requirement in its proper layer without fixing one interaction mechanism.

- [The scientific problem and its expressive burden](description.md) define the requested distinctions and the scope boundary.
- [The formal microbial-population target](target-system.yml) covers resource-mediated and direct higher-order interaction models under complete member-specific laws.
- [The stable-coexistence capacity](phenomenon.yml) records feasibility and local dynamical stability as separate observables.
- [Necessary and sufficient coexistence constraints](question.yml) state the two implication directions as separate proof obligations across the admitted variants and resource supplies.
- [The complete-dynamics operators](operators.yml) define equilibrium and linearization without reducing either target variant to the other.
- [The current specification assessment](issues.md) distinguishes the typing limit caused by variant-specific state spaces from the requested modal result.
- [The symbols and operators this problem declares](vocabulary.yml) collects every declaration across its records, so a new notation can be chosen without reopening each file. The `gnomon vocabulary` command builds [a table of the same record](vocabulary.md) on request.
