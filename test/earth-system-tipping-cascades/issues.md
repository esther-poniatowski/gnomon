# Current assessment of the specification of tipping cascades

## Result

The records now separate the particular target, the actual Earth system, from its partial closure. The target record identifies four selected subsystems and the directed interactions among the four. The prescribed scenario remains external. Four named scope axes distinguish the sources of predictive spread. Event horizons and right censoring are explicit. The probability of each transition and the distribution of its time carry separate metrics.

## Global issue

The framework offers no constructor that gives the marked transition sequence a precise value set. Consequently, [the operator pairing identities with event times](operators.yml) and the value set of `Z` remain abstract. `PZ` can therefore refer only to an abstract carrier set of event sequences. A constructor for finite event sequences with marks and censoring would close the last typing gap.

## Local decisions still required

The numerical tolerances on probabilities and on timing are design choices of the inquiry and remain open. The exact definitions of the targets also remain open. Current evidence likewise does not determine the formal detection expressions for the actual Earth system. The `maturity` block records each open specification. The specifications stay open because values taken from the stylized network turn a model result into a claim about the actual system without warrant.

Unlike these open specifications, the law of transition sequences and the direction and magnitude of the overshoot effect for the actual Earth system remain outputs that the prediction must deliver.

## Answer and assessment trial

[The answer drawn from the stylized network](answer.yml) records a published model result and states its idealizations. [The assessment passes the paired statistical comparison](assessment.yml) but fails on empirical scope and actual modal strength. Closure and robustness also fail. Fidelity stays pending because the accuracy bounds are open and no invented tolerance may settle the verdict.

The trial confirms that a candidate answer needs an explicit domain for its claim. The existing fields do not supply that domain. The `variant` field cannot state that the result applies only to a stylized dynamical subclass. An idealization entry cannot state this restriction either, because an idealization names a *distortion*, whereas the restriction concerns the population over which the claim is quantified. The gap recurs across cases and is recorded among [the findings shared by all answer trials](../answer-assessment-template-issues.md).
