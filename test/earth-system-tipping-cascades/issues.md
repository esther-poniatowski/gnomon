# Current assessment of the tipping-cascade specification

## Result

The records now separate the particular Earth-system target from its partial closure. They identify four selected subsystems and their directed interaction organization. The prescribed scenario remains external. Four named scope axes distinguish the sources of predictive spread. Event horizons and right censoring are explicit. Probability and time-distribution outputs carry separate metrics.

## Global issue

The marked transition sequence has no precise value-set constructor. Consequently, [the sequence operator](operators.yml) and the value set of `Z` remain abstract, while `PZ` can only refer to that abstract carrier. A constructor for finite event sequences with marks and censoring would remove this last typing gap.

## Local decisions still required

The numerical probability and timing tolerances are inquiry-design choices and remain open. The exact target definitions and formal detection expressions also remain open because current evidence does not determine them for the actual Earth system. The `maturity` block records each open specification; filling the specifications with the stylized network model would incorrectly promote a model result to a claim about the actual system.

The transition-sequence law and the direction and magnitude of the overshoot effect remain prediction products. No answer or assessment record is yet warranted.
