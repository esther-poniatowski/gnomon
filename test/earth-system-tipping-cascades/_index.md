# Earth-system tipping cascades

The Earth-system case tests predictions for a partially known coupled system whose possible futures reflect several sources of uncertainty.

- [The tipping-cascade problem and its expressive burden](description.md) fix the case brief and its expressivity requirements.
- [The selected subsystems of the actual Earth system](target-system.yml) specify the provisional empirical target and its incomplete dynamics.
- [The distribution of future transition sequences](phenomenon.yml) represents complete marked transition sequences over an ensemble of possible futures.
- [The overshoot comparison](question.yml) requests a statistical prediction and separate accuracy requirements for transition probabilities and event times.
- [The marked-sequence constructor](operators.yml) builds ordered transition identities and event times.
- [The current specification assessment](issues.md) separates the residual marked-sequence typing gap from unresolved scientific and design choices.
- [The symbols and operators this problem declares](vocabulary.yml) collects every declaration across its records, so a new notation can be chosen without reopening each file. The `gnomon vocabulary` command builds [a table of the same record](vocabulary.md) on request.
